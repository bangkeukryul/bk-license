# 🔑 BK라이선스

BK Agent(비케이) 프로그램 라이선스 관리자 앱 — **관리자 전용**

- 라이선스 발급 (기기 1대 잠금 · 영구 / 7일 / 1개월 / 3개월 / 1년 / 날짜 지정)
- 발급 장부 · 만료 알림 · 연장 · 해지
- 잠글 프로그램 설정 파일(license-config.json) 만들기 → bk-card 저장소에 올림

비밀 도장(개인 키)은 관리자 휴대폰 안에만 비밀번호로 잠겨 저장돼요. 이 저장소에는 비밀 정보가 없어요.
라이선스 넣기(고객용) 화면: https://bangkeukryul.github.io/bk-card/activate.html
